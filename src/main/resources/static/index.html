Placing an order runs a saga: reserve stock → authorize payment → confirm. Any step that fails triggers a compensating action instead of a rollback — because the payment call is external and can't be rolled back. Idempotency keys absorb retries, an atomic conditional decrement blocks oversell, and every outcome is published through a transactional outbox to Kafka.
